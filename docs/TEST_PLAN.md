# Android 16 真机测试计划（首轮）

## 测试环境

- Android 16 / API 36 真机；记录厂商、ROM 版本、分辨率、密度、电池模式。
- 目标 App 版本、安装渠道、网络环境固定；清后台冷启动。
- 首轮至少覆盖 Pixel/AOSP 与主流国产 ROM；按原技术方案扩展至 8–10 台设备。

## W0 门控

| 项目 | 目标 | 记录方式 |
|---|---:|---|
| 开屏窗口识别率 | ≥90%，至少 6 台机型达标 | 10 个目标 App × 每机 10 次冷启动 |
| 单次处理耗时 | P95 <300ms | 从窗口事件到处理完成 |
| 误点 | 100 次冷启动 0 次 | 记录每次动作目标和前后台包名 |

## 当前基座冒烟测试

1. 新安装后，首页应显示无障碍未授权。
2. 不授权无障碍时，App 管理和体检页面仍可正常使用。
3. 授权无障碍后，系统服务列表显示用途描述。
4. 任一目标 App 默认不开启；只有用户确认后才允许读取其窗口节点。
5. 关闭某个 App 的授权开关后，服务不得继续读取该 App 的窗口树。
6. 构造 5000 节点或超深层级页面，采集器应在 800ms 预算内返回部分结果。
7. 数据库字段、日志和网络抓包中不得出现屏幕 text/contentDescription。
8. 23 项检查初始均为“未验证”；未验证项不计分，覆盖率不足 80% 时不得对外导出。

## 通过标准

本项目没有连接目标 App 自动化测试农场，也没有在本交付环境执行 Android Gradle 构建。任何性能、兼容性和自动跳过指标必须在目标真机上重新测量并留存报告。
